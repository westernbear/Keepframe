## Blind A/B: brief vs kf-script view (P1 Task 7)

`scripts/ab_views.py`; 6 clips × 2 views = 12 packets, 10–14 questions each (auto-gold from `scene.json`: visibility, end of last move, glyph reveal, ease, largest text and colour, z order; read-gold from `gold-reads.md` mapped to IR ids; edit targets). One fresh Claude subagent (Sonnet) per packet, reading only its packet. No production LLM is configured in this container.

| Run | Brief comprehension | kf comprehension | Brief edit | kf edit | Rule (kf edit ≥ brief and kf comp ≥ brief + 10) |
|---|---|---|---|---|---|
| 1 (`ab-run1/`) | 82.5 | 84.2 | 100 | 92.9 | not met |
| 2 (`ab/`) | 82.5 | **94.7** | 100 | **100** | met |

- Run 1: kf-script lost the edits whose targets the 24/48k budget had dropped from the view (mk543's email message), and the two "largest text" questions were ambiguous (area vs font size) for both views.
- Between runs: elements that do not fit the budget became one-line summaries instead of disappearing (never drop an element, as the brief never drops one under 40), and "largest" was defined as box area. Both views were re-asked.
- kf-script's gains: glyph reveals (e24's typed prompt — invisible in the brief), eases, end of last movement, largest text. Its remaining misses: z order (fixed afterwards: the header now says `data-track-index` is the stacking order) and one "last movement" answer that counted sub-threshold noise keys.
- **The default view stays `brief`.** Run 2 meets the pre-registered rule, but it was taken after a change motivated by run 1 on the same questions, with a stronger model than production and n = 6 clips. The switch waits for a confirmation run on fresh clips (P2's synthetic cases) and, when credentials exist, the production model (`scripts/ab_views.py run`). Until then `KEEPFRAME_AGENT_VIEW=kfscript` turns it on.
