2D 모션 · UI 녹화

유지할 것과 바꿀 것을 지정하세요.

평면 2D 모션그래픽과 UI 화면 녹화를 측정해 편집 가능한 장면으로 만듭니다. 실사 푸티지는 거부합니다.

새 레퍼런스
측정 → IR → 검수

업로드·분석·검수

01

업로드

구간 지정이 기본. 전체 영상은 샷 분할 후 장면별로 분석합니다.

02

분석

장면을 IR로 바꿉니다. 장면당 수 분 걸릴 수 있습니다. GPU 사용을 허용합니다.

03

검수

유지 조건을 지정하고 재할당·마스크·박스·텍스트로 보정합니다. 재시도 4회·에셋 생성 2회는 화면에 표시만 합니다.

받지 않는 것

  • 실사 푸티지는 열리지 않습니다.
  • 평면 2D 모션그래픽과 UI 화면 녹화만.
  • 재시도 상한 4회, 에셋 생성 2회 — 표시만, 조작 없음.
